- 👤 Face Verification

- 📍 Geofencing
- 📴 Offline Attendance
- 🔄 Background Synchronization
- 📊 Attendance Analytics
- 📱 Flutter Mobile Application
- 🌐 React Web Dashboard
- ⚙️ Laravel Backend
- 🧠 Python AI Service
